# Custom Audio Files Directory

You can place your own audio files (such as MP3, WAV, OGG, or AAC) directly in this folder:
`/public/audio/`

### Supported File Names (Pre-linked)
- `monsoon-rain.mp3` -> Will automatically be used for "Monsoon Rain & Distant Thunder"
- `forest-river.mp3` -> Will automatically be used for "Pine Forest Stream & Mountain Breeze"
- `ocean-waves.mp3` -> Will automatically be used for "Midnight Ocean Waves & Deep Tide"
- `hindi-bansuri.mp3` -> Will automatically be used for "Raag Desh / Bansuri Twilight Chill"
- `hindi-acoustic.mp3` -> Will automatically be used for "Midnight Chai & Bollywood Acoustic Lo-Fi"
- `deep-focus.mp3` -> Will automatically be used for "Deep Focus Brown Noise"

### Adding Any New Hindi Song or Track:
1. Copy your `.mp3` file into this `/public/audio/` folder (for example: `tum-hi-ho.mp3`).
2. You can also click the **"Upload / Select Local MP3"** button directly inside the music player in the portfolio to play ANY song on your device right away!
3. If no physical MP3 file exists in this directory, the portfolio's built-in **Web Audio Engine** automatically synthesizes real natural rain, water flow, and Indian tanpura/flute drone soundscapes in real-time right inside your browser!
